# TI-84 CE Project Knowledge

Esta pasta guarda conhecimento verificavel do projeto sobre desenvolvimento para TI-84 Plus CE, TI-84 Plus CE Python Edition e TI-83 Premium CE usando CEdev/toolchain CE.

Use esta pasta para manter:

- Links ou copias locais da documentacao CE C/C++ Toolchain.
- Exemplos oficiais e exemplos pequenos ja validados.
- Anotacoes sobre `graphx`, `keypadc`, `fileioc`, `ti/getcsc`, debug e CEmu.
- Comandos de build, clean build, geracao de `.8xp` e smoke test.
- Checklist de validacao no hardware real.
- Diferencas conhecidas entre TI-84 Plus CE comum e Python Edition.

Regras para manter esta pasta util:

- Prefira fontes oficiais, headers instalados e exemplos da toolchain.
- Registre de onde veio cada informacao tecnica importante.
- Quando uma API, limite ou comportamento nao tiver fonte confiavel, marque como pendente em vez de tratar como fato.
- Mantenha comandos com diretorio de execucao, versao da ferramenta quando possivel e resultado esperado.
